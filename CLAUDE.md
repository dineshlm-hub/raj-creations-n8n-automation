# Raj Creations n8n Automation

## Project
This repository contains the Raj Creations n8n automation system and its supporting website, workflows, documentation, spreadsheets, and catalog files.

## Important rules

- Inspect existing code and workflows before making changes.
- Do not delete working functionality unless explicitly instructed.
- Do not overwrite existing n8n workflows unnecessarily.
- Preserve existing workflow IDs and node logic wherever possible.
- Never hard-code API keys, passwords, tokens, or credentials.
- Never commit .env files or credential files.
- Keep secrets in environment variables or n8n credentials.
- Make the smallest safe change necessary.
- Do not change package versions or infrastructure configuration without a reason.
- Test changes before considering the task complete.
- Clearly explain what was changed and what was tested.

## Website

- Preserve the current website structure unless a redesign/change is explicitly requested.
- Do not remove product/catalog assets without checking their references.
- Keep the website deployable to the existing hosting setup.

## n8n

- Understand the complete workflow before modifying it.
- Preserve existing webhook and integration behavior unless instructed otherwise.
- Do not replace credentials with hard-coded values.
- Avoid destructive changes.
